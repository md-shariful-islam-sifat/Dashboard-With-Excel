# Dashboard with Excel

## Workflow

**Raw Data → Cleaning → Transformation → Analysis → KPIs → Insights → Dashboard**

### 1. Raw Data

The process starts with collecting and importing the raw dataset.

**Activities:**

* Collect raw data from the source
* Import data into the analysis environment
* Understand the dataset structure
* Identify columns, data types, and records
* Check for missing or inconsistent values

### 2. Data Cleaning

The raw data is cleaned to improve its quality and reliability.

**Activities:**

* Handle missing values
* Remove duplicate records
* Correct inconsistent values
* Fix data types
* Handle invalid or incorrect records
* Standardize text and categorical values

### 3. Data Transformation

The cleaned data is transformed into a suitable format for analysis.

**Activities:**

* Create calculated columns
* Apply required formulas
* Format dates and numerical values
* Create new variables
* Group and aggregate data
* Prepare analysis-ready datasets

### 5. KPIs

Key Performance Indicators (KPIs) are calculated to measure important aspects of the dataset or business performance.

**Examples:**

* Total Sales
* Total Profit
* Profit Margin %
* Total Orders
* Total Quantity
* Average Order Value
* Average Discount
* Total Customers
* Cancellation Rate
* Return Rate
* Average Units per Order	

### 6. Insights

The analysis and KPIs are used to generate meaningful insights.

**Focus areas:**

* Identify important trends
* Find high and low performing categories
* Detect unusual patterns
* Understand customer or business behavior
* Identify areas for improvement
* Support data driven decision making

### 7. Dashboard

The final results are presented through an interactive dashboard.

The dashboard provides:

* KPI cards
* Interactive charts
* Trend analysis
* Category comparisons
* Filters 
* Key business insights
* An easy-to-understand overview of the data
